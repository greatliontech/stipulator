# A gap's excuse is judged against the row's winning bucket alone

The excuse walk judges a requirement's red by its bucket — one class
per row, broken outranking stale outranking uncovered — so a gap
excusing `broken` alone drops a row from the violations even when a
stale-class red (a drifted content pin, an unpinned shape, a stale
attestation) stands behind that bucket undeclared. The boundary
classes now look behind the bucket at the row's constituent red facts
(REQ-check-verdict's scoped class beside an excused stale class); the
excuse judgment does not. Whether an excuse must cover every red class
a row carries — a per-row set of classes judged against the gap's
declared set — or the winning class alone, as REQ-gate-no-undeclared
reads today, is a semantic call over what a gap may absorb.

Lands: user decision.
