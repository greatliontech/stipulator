`(invariant)` in its spec — a closed verb inventory whose member set
is enforced by example-class inventory walks bound as `tests` — was
judged by the user to be adequately enforced (a property witness over
a closed list re-derives the list and checks it against itself).

analyzer proof (invariant); an attestation that can never render is
refused, not recorded."

requirement (`(invariant)` → `(wire)`, whose cell admits an executed
witness) and re-pin it — a spec-text amendment the consumer had to
derive from the policy table. Ask: the refusal (and `explain` on an

a for-all property is an invariant" — so the author is sent to the
one edit that can render the decision rather than left to hunt for a
gap-shaped excuse.
