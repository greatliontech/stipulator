# Ephemeral Retained Binary Poisoning, Missing `ScratchRoot`, Delayed `testlog` Removal, Inverted Variant Refusal Attribution & Unisolated Test Caches

- **Status:** Open
- **Governing contract:** [`docs/specs/evidence.md`](../specs/evidence.md) (`REQ-evidence-witness-freshness-inputs`, `REQ-evidence-witness-freshness-bracket`, `REQ-evidence-witness-freshness-exemptions`, `REQ-evidence-witness-freshness-diagnosable`, `REQ-evidence-witness-freshness-purity`, `REQ-evidence-witness-cache-format-eviction`, `REQ-evidence-store-gc`), [`docs/specs/backends/go.md`](../specs/backends/go.md) (`REQ-go-retained-test-execution`, `REQ-go-owned-processes-telemetry-home`)
- **Lands:** Chunk 1 in [`docs/plans/plan.md`](../plans/plan.md)

## Problem

1. **Ephemeral `/tmp/stipulator-retained-<id>/package.test` and Owned Telemetry Home Enter `Fingerprint.RuntimeInputs` and Invalidate Warm Batch Witnesses**
   - `retainedbuild.go` (`lines 51, 95`) compiles each package's test binary into `os.MkdirTemp("", "stipulator-retained-*")` and removes that directory in `retainedArtifact.Close()` after the package finishes (`execute.go` line 314).
   - During execution, tests reading their own executable (`os.Executable()` / `/proc/self/exe` / symbol inspection) record `open` or `stat` on `/tmp/stipulator-retained-<id>/package.test` in `GODEBUG=testlogfile`. Likewise, child `go` invocations read the owned telemetry config home (`REQ-go-owned-processes-telemetry-home`, e.g. `/tmp/stipulator-telemetry-off-<uid>/go/telemetry/mode`).
   - `prepareNativeAttempt` ([`internal/backends/golang/nativeexecution.go`](../../internal/backends/golang/nativeexecution.go) lines 286–289) omits `artifact.Path` (and the owned telemetry config home) from `gofresh.ProcessDescription.ExcludedPaths`, and `finishNativeRun` (`lines 58–90`) calls `Unit.Close` *before* `retainedArtifact.Close()` deletes the directory.
   - Because `/tmp/stipulator-retained-<id>/package.test` still exists on disk at `Unit.Close` time, `gofresh`'s `ephemeralScratch` check (`os.IsNotExist`) does not elide it:
     - Without `assume_pure` (e.g. `pew`), `93` batch witnesses immediately fail post-run validation (`runtime input not covered by observation bracket: /tmp/stipulator-retained-.../package.test`).
     - With `assume_pure: true` (e.g. `gofresh` `race:core`), `Unit.Close` attaches `/tmp/stipulator-retained-<id>/package.test` to `Fingerprint.RuntimeInputs` (honoring `REQ-purity-override` `guard-drift`), passes publish-time validation while the binary still exists, and then `retainedArtifact.Close()` deletes the binary — causing **`693/694` batch witnesses in `race:core` to fail `check_verdict` on the next run** with `stale: runtimeinputs (moved: path /tmp/stipulator-retained-<id>/package.test)`.

2. **Missing Per-Attempt `ScratchRoot` (`TMPDIR`) & Delayed Removal of Multi-GiB `stipulator-testlog-*.txt` Files**
   - `prepareNativeAttempt` ([`internal/backends/golang/nativeexecution.go`](../../internal/backends/golang/nativeexecution.go) lines 286–289) and [`internal/backends/golang/retainedenv.go`](../../internal/backends/golang/retainedenv.go) leave `ScratchRoot: ""` and child `TMPDIR` pointing at ambient `/tmp`, so temporary files created via `os.CreateTemp("", ...)` inside tests or child tools are neither elided under a dedicated scratch root nor swept per attempt.
   - `finishNativeRun` (`nativeexecution.go` lines 58–90) leaves `a.logPath` (`957 MiB` on `gofresh`, `2.1 GiB` on `gomutant` and `stipulator/internal/backends/golang`) on `/tmp` (`tmpfs` RAM) after `Unit.Close` finishes reading it, deferring `a.release()` until whole-invocation exit (`execute.go` line 548) and leaking `stipulator-testlog-*.txt` files on interrupted runs.

3. **Variant-Round Loop Overwrites Primary (`round == 0`) Refusal Attribution (`witnessrun.go:998, 1000, 1022`) & Store Variant Bloat**
   - `prepareWitnessGroups` ([`internal/backends/golang/witnessrun.go`](../../internal/backends/golang/witnessrun.go) lines 891–1060; variant-round loop at lines 968–1049) checks variants ordered most-recently-installed first (`round == 0` is the last run's record; `round > 0` are older historical variants).
   - When every variant is stale, lines 998, 1000, and 1022 unconditionally overwrite `wg.executedWhy[s]` on each round, replacing `round == 0`'s actionable refusal (`runtimeinputs (moved: path /tmp/stipulator-retained-.../package.test)`) with the oldest historical variant's refusal (`closure`), obscuring why the latest record failed (`REQ-evidence-witness-freshness-diagnosable`).
   - Meanwhile, `~/.cache/stipulator/witnesses/` accumulated `11,989` JSON files (`1.8 GiB`) across historical schema/manifest versions (`4,508` observed refusals on `manifest version 2` alone).

4. **Unisolated `XDG_CACHE_HOME` & Volatile OS Reads (`/proc`, `/sys/fs/cgroup`) in `stipulator` Integration Tests**
   - Tests in `internal/cmd`, `internal/witnesscache`, and `internal/backends/golang` invoke `gofresh` and `stipulator` without setting a per-test `XDG_CACHE_HOME` (while preserving `GOCACHE`), reading and mutating `6,718+` files in the user's live `~/.cache/gofresh` and `~/.cache/stipulator`.
   - Each persisted witness record in `internal/cmd` (`70` records) and `internal/witnesscache` (`35` records) consequently embeds a `3.15 MiB` `RuntimeInputs` manifest (`220 MiB` of JSON for `internal/cmd` alone) that immediately stales when any later package writes or prunes `~/.cache/gofresh`, and triggers `observation.BracketMoved` (`RuntimeInputSpanError`) during long runs.
   - In addition, `resident.Readings()` calls inside `internal/backends/golang` tests open `/sys/fs/cgroup/user.slice` (`1,170` opens) and `/proc/<pid>/status` + `/proc/<pid>/task/<tid>` (`195` opens), which hit `volatileOSPath` (`Unverifiable: true`, discharged in `stipulator` only because `.stipulator/policy.textproto` sets `assume_pure: true`, without entering path digests into `RuntimeInputs`).

## Soundness Constraints & Resolution Scope

1. **Runner-Owned `ExcludedPaths` vs. `ObservationExclusions` (`REQ-evidence-witness-freshness-inputs`)**:
   - Update `REQ-evidence-witness-freshness-inputs` in [`docs/specs/evidence.md`](../specs/evidence.md) lines 340–354 to expand the runner-owned observation-exclusion class beyond `.` and `.git` to include the attempt's own retained test binary (`REQ-go-retained-test-execution`, whose compiled content is already pinned by closure, build, and toolchain guards) and the owned telemetry config home (`REQ-go-owned-processes-telemetry-home`).
   - Pass those ephemeral runner-owned paths **only** on `gofresh.ProcessDescription.ExcludedPaths` (`nativeexecution.go` line 288), **never** on `n.ExcludedPaths` / `witnesscache.Record.ObservationExclusions` (where random temp-dir names would fail `roundCandidates` at `witnessrun.go` lines 868–880 on the next run with `"recorded under a withdrawn observation exclusion"`).
2. **Per-Attempt `ScratchRoot` & Immediate `logPath` Removal**: Provision a per-attempt `ScratchRoot` directory wired to both child `TMPDIR` and `gofresh.ProcessDescription.ScratchRoot`, swept on attempt release, and remove `a.logPath` immediately after `closeNativeProcess` completes.
3. **Primary Variant Refusal Attribution, `witnesscache.GC` Admission Alignment & Batch Record Installation**:
   - Record `wg.executedWhy[s]` from `round == 0` (the most recently installed variant) rather than overwriting it with older fallback rounds (`round > 0`).
   - Align `gcSince` ([`internal/witnesscache/witnesscache.go`](../../internal/witnesscache/witnesscache.go) lines 838–861) with `loadEntry(name, data, dir).record != nil` (matching `resolutioncache.GC` at `resolutioncache.go` lines 296–302) so `stipulator prune` (`REQ-evidence-store-gc`) sweeps version-9 envelopes carrying permanently refused `manifest version 2` or invalid evidence structures (`4,508` stale files), while guarding `sweepLedgers` (`REQ-evidence-witness-cache-refusals`) so compartment ledgers are never deleted when a referencing record's `os.Remove` fails.
   - Add batch `witnesscache` installation (`InstallBatch`) for `installRecords` ([`internal/backends/golang/packageleg.go`](../../internal/backends/golang/packageleg.go) lines 107–123): validate `fileName(rec)` and marshal per record first, call `installLedger` once per coordinate that has `>= 1` valid record (never writing an orphan ledger when all records for a coordinate fail validation), write each valid record independently collecting per-record errors and exact landed records (rather than `recordstore.Store.Install`'s fail-fast mid-loop abort), and run a single final `s.scan()` variant-eviction pass under one store lock.
4. **Consolidate Test Cache Isolation into `internal/testenv` (Removing Production `normalize.go` `init()` State)**:
   - Move `NeutralAmbient` and `ambientGoCache` out of production [`internal/backends/golang/normalize.go`](../../internal/backends/golang/normalize.go) (`lines 669–699`, eliminating the production `init()`-time `os.Getenv("GOCACHE")` / `os.UserCacheDir()` read and latent `GOENV` cache-miss bug) into a new test-only `internal/testenv` package backed by `gotool.GoBuildCache` ([`internal/gotool/env.go`](../../internal/gotool/env.go) lines 156–203).
   - Wire suite-level `testenv.IsolateMain(m)` into `TestMain` across `internal/cmd`, `internal/backends/golang`, `internal/witnesscache`, `internal/mcpserver`, and `internal/check` (so every test defaults to an isolated temporary `XDG_CACHE_HOME`/`XDG_STATE_HOME` while pinning warm `GOCACHE` across all ~45 per-test `t.Setenv("XDG_CACHE_HOME", t.TempDir())` overrides), delete the 3 duplicate `neutralAmbient` test wrappers (`check_test.go`, `hygiene_prepare_test.go`, `check_tool_unix_test.go`) plus `interrupt_unix_test.go`'s ad-hoc `go env GOCACHE` shell-out, and leave `resident.Readings()` volatile `/proc` and `/sys/fs/cgroup` blindspots cleanly covered by `assume_pure: true` with zero path entries.
