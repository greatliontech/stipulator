# A knob's terse clause serves both faces from one document line

REQ-mcp-guidance renders every schema description and flag usage
string from the guidance document's knob text — the first clause up to
its first semicolon outside parentheses — and one knob line documents
both faces, so a clause whose parenthesis names the other face ("
(comma-separated on mcp; repeatable on the cli)") reaches each face
carrying the other's prose: six served descriptions name the cli, five
usage strings name mcp. The two-surfaces doctrine wants each face's
prose written for its reader. Either the document marks a per-face
terse clause, or the clause rule stops at a parenthesis naming the
other face, or the cross-face prose is accepted as the price of one
line — a surface-doctrine judgment.

Lands: user decision
