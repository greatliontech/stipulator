## First-Principles Architectural Derivations & Soundness Audit

- **Uniform Callable & Non-Callable `gofresh.SourceResult` Representation**:
  - `gofresh.SourceResult` natively scans and hashes both callable symbols (`func`, methods) and non-callable declarations (`type`, `var`, `const`, struct fields `T.N`, interface methods) via `staticDecl` (`ComputeMaximalFactsBatch` + `TestVariantClosure` + `ToolchainContent` + `AdmissionPolicy` + `Guards.{Toolchain,BuildConfig}`), omitting runtime, purity, observation, and dynamic-state fields by construction (`gofresh.Fingerprint.MarshalJSON` itself rejects runtime or dynamic-state fields on `SourceResult`).
  - Consequently, `Record` needs neither `SourceTiers` projection nor a zero-fingerprint special case for non-callables, and `Served` needs no parallel `parseNonCallableSymbols` AST scanner.
- **Ordered Multi-View Precedence & Cross-View Seeding Soundness**:
  - A symbol resolved in `r.Selection` under ordered policy selections `[sel_0, ..., sel_{k-1}]` records `Views` in exact policy order:
    - Every view `i < idx(r.Selection)` has `Present == false` and zero `Fingerprint` (certifying declaration-precedence absence).
    - View `r.Selection` has `Present == true` and its `SourceResult` `Fingerprint`.
    - Every view `i > idx(r.Selection)` has `Present == true` with its `SourceResult` `Fingerprint` (covering cross-view seeding helpers in `TestImports`/`Deps` via `gofresh` core closure) or `Present == false` when not declared in that view.
  - Passing `"stipulator/source-classifier=" + sourceClassifierIdentity` in `BuildDescription.Inputs` binds the analyzer binary's image digest directly into `Guards.BuildConfig`.
- **Closing Interval Re-Observation (`CheckingUnit.Close`) & Per-Package Isolation**:
  - For every served record's `Present == true` view entry, `closeServedViews` binds the captured `*gofresh.Snapshot` (`snap.BindRuntime`), opens a narrowed `*gofresh.CheckingUnit` over the surviving served subjects (`binding.BeginCheck(subjs)`), and calls `unit.Close` after `beforeServingCloseForTest`. `gofresh`'s `closeValidationReobservation` re-observes source closures, `go.mod`/`go.work`, and `Guards` (including raw `GOENV` file bytes), revoking affected served symbols with `"source dependencies moved during serving"` on `ErrViewChanged`.
  - For any served record relying on `Present == false` in a view or carrying an ambiguous dotted package candidate (`len(symbolPackageCandidates(sym)) > 1`), closing re-verifies `verifyInventoryUnchanged` and subject absence in declared packages so an earlier declaration or dotted subpackage introduced mid-serving is caught without querying unrecorded packages.
  - When a multi-package `Snapshot(..., SourceResult)` fails on a broken package, `captureSourceView` falls back to one `Snapshot` per package: unaffected packages (including packages served via `scanfacts` and validated by `CheckingUnit.Close`) still serve/capture while each broken package is queried once and degraded naming its affected symbols; when 0 packages succeed in `selection` phase (e.g., `go env` / shared configuration failure), a single whole-selection degradation notice (`selection "<key>": ...`) is emitted and later views are skipped once `len(candidates) == 0`.
  - During `serveRecords`, views visited while `len(candidates) > 0` probe all recorded symbols in non-failed packages so `s.checkedViews` covers stale recorded symbols across secondary views too, allowing `openingCapture` to reuse `s.checkedViews` with zero extra `gofresh` engine spawns.
